# 图文卖点组工作流

“图文卖点组（Feature Highlights）”用于电商详情页中的功能点、利益点或能力点表达。一个卖点项由“透明图标 + 可编辑短标题 + 可编辑说明”组成；多个卖点项作为一个可排布的组存在。它不把文字交给图片模型生成，也不把商品参考图事后贴到底图上。

## 完整链路

1. 版式模板通过 `feature_slots` 声明卖点组预留区、最大项数、行列、图标位置、间距和卡片样式；图片模型只接收“在该区域保留低细节、无字空间”的构图约束。
2. 内容规划通过 `PageItem.feature_points` 保存结构化卖点。每项包含标题、说明、图标语义和 `fact_refs`，文案必须能追溯到商品卖点或参数，不能由模型虚构。
3. 图片模型基于全部商品参考素材生成商品、角度、场景、材质和光影，不生成营销文字或功能图标。
4. GPT Image 2 以透明 PNG 生成同风格图标组；调用失败或透明度不合格时，系统使用自有几何图标降级，页面生产不会因此丢失。图标质量和尺寸由独立的 `PCP_ICON_QUALITY`、`PCP_ICON_PACK_SIZE` 控制，不修改主图的尺寸和 High 质量配置。
5. 确定性合成器分别输出 `base.png`、`icon_layer.png`、`text_layer.png` 和 `composed.png`。中文文字始终由字体引擎绘制，内容可控且可再次编辑。
6. 质检页的“页面图层工作台”以组/子项层级展示卖点。组可以拖拽、缩放、调整行列、图标位置和间距；子项可以修改文案、字号、颜色、图标缩放和主题色，并能单独重新生成或上传透明 PNG/WebP 替换图标。
7. 应用图层只重新生成透明图标/文字层与最终合成图，不会修改无字底图。之后可手动重新质检，也可按既有审计规则人工确认。

## 质检与交付证据

- 文案检查同时覆盖标题、正文和每个卖点项，`fact_refs` 缺失会进入问题列表。
- 布局检查覆盖卖点组安全区和商品主体遮挡；QA 证据保存组坐标、重叠率、图标来源与合成溯源。
- 正式导出包含最终图、底图、透明图标层、透明文字层、每个单图标、QA 文件和 `project_summary.json`；长图拼接继续使用最终合成图，因此与卖点组兼容。

## 内置验收示例

部署后可直接打开 `[示例] 4K 横版 · 三项图文卖点`。该示例使用 3840×2160 横版模板，在左侧设计三项卖点卡片、右侧保留真实商品场景，并保留完整分层文件与审计元数据，无需先调用云端模型。

## 当前结论

新 Product Content Studio 已经从旧“项目→模板→配方→审核”流程中分离，以五个直接创作工具为主入口。新前端只调用 `/api/studio/*`，新后端只读写 `data-refactor/`，不导入旧业务模块、旧运行数据或 Azure 配置。旧目录移除不会改变新 Studio 的启动与数据边界。

## 已完成的本地产品能力

| 范围 | 实际完成内容 |
|---|---|
| 五工具工作台 | 电商套图、A+ 详情图、营销主图、场景图、卖点图；切换工具保留各自最近草稿 |
| 输入与配置 | 商品/风格/Logo 用途分离，多图排序，名称、SKU、品类、事实及来源，中英文、文字模式、品牌色/字体/Logo，7 种比例、1K/2K 与 1/2/4 候选 |
| 套图与 A+ | 套图 10 类用途、最多 15 页；A+ 8 类模块、最多 6 页，方案可改文案/画面/顺序，重新规划保留可恢复的方案版本；整组尺寸之外可在生成前为单页/模块覆盖输出尺寸 |
| 任务与恢复 | 不可变提交快照、防重提交、按候选保存、两个图片请求并发、候选占位状态、部分失败单项或统一补生成、停止未派发项、重启后把在途结果标为待确认而不盲目重发 |
| 版本与 AI 修改 | AI 生成、修复、AI 修改与手动版本不覆盖；用户选图后不被后到修复版抢回；AI 修改仅针对明确选中的底图并保留已应用人工图层 |
| 智能质检 | 商品外观、文案事实、可读性/版式和品牌分项；证据化关键错误总分上限 59；低于 60 只追加一次 AI 修复；质检服务安全重试两次，仍失败时保留无分数状态并支持手动重检；人工编辑不质检 |
| 手动编辑 | 独立文字/图片图层，画布内改字，字体、字号、颜色、样式、对齐、行距、字距、描边、阴影，移动/缩放/旋转/复制/删除，图层排序/锁定/隐藏，撤销重做和自动恢复草稿；服务端对图层类型、尺寸、样式、唯一标识及本地素材引用进行严格校验 |
| 素材与复用 | 商品图、风格参考、Logo、风格预设和作品快照；收藏为独立快照，只读预览后可建副本继续，换商品复用不带旧商品事实和专属文案 |
| 历史与删除 | 创作记录显示结果缩略图、工具、状态和版本数，支持搜索/筛选；历史与素材各有 30 天回收站，在途任务阻止彻底删除，收藏快照和其他引用保护共用文件，无引用文件才物理回收 |
| 导出与像素证据 | 单图 PNG/JPG（JPG 白底）、按页序 ZIP、2048 宽等比长图，共用编辑器合成器；缺页明确提示，超出浏览器安全限制时要求改用 ZIP，不裁掉或拉伸；每个版本保留请求像素、实际像素及是否匹配的服务端记录 |

## 示例与界面验证

`frontend/public/studio-demo/` 现包含一张原始洗衣机参考和六张 Codex 生成作品：三张中文营销/场景/卖点图，以及三张英文 A+ 首屏/核心卖点/场景模块。每张按实际像素记录质检结论；已知的控制面板或侧面偏差被保留为问题，没有被写成满分案例。

已在本地浏览器实际验证：电商套图三页回放、A+ 三模块回放、品牌偏好、整组及单页尺寸配置、商品参考对比与 1:1/适应画布、素材库六张案例、创作历史缩略图/状态/筛选以及导出弹窗。新回放详情能同时展示请求像素、实际像素和不拉伸说明；未改动的提交快照不再因 JSON 字段顺序误报“设置已修改”。

3. 1K/2K 尺寸是应用预设并已进入任务包，不代表某个外部图片模型的全部档位已通过真实请求验收。
4. 本轮按要求未调用 Azure，旧 Azure 验收记录不作为新 Studio 的完成证明。

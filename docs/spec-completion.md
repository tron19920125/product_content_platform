## 运行模式

- `PCP_GENERATION_MODE=local`：默认。不依赖外部服务，用于功能演示、自动化测试和稳定回归。
- `PCP_GENERATION_MODE=azure`：通过平台自有适配层调用 Azure 图片生成或参考图编辑。
- `PCP_QA_MODE=local`：默认。使用确定性的文字层、版式、事实和视觉规则证据。
- `PCP_QA_MODE=azure`：调用 Azure AI Vision OCR，并将 OCR、参考图、视觉差异和审查计划交给 Azure OpenAI 多模态审查。

Azure 活体调用需由运行环境提供服务端凭证。本次验收已使用真实 Azure 图片、Vision OCR 和 LLM 审查资源完成 1 页迭代及最终 5 页 `2048x2048 / High` 全量生产，不再仅依赖适配器模拟。

- 后端：67 项 Python 自动化测试全部通过，覆盖 Azure 路由/身份、生产、分层合成、QA、配方、批量、导出和服务重启。
- 前端：TypeScript 构建与 Vite 生产构建通过。
- 本地批量：5 个 SKU、25 页完成生产和审核；批量 ZIP 含 5 个独立 SKU 目录；服务重启后仍保持 5/5 完成。

- 历史 Azure 五页验收采用 `azure-gpt-image / 2048x2048 / high / layered_product`，最新候选全部 QA 98 分通过并获批准；正式 ZIP 共 31 个条目、78.6 MB。该记录是旧贴层方案的历史证据，不代表当前默认策略；当前默认已迁移到 `model_edit`，并单独执行多参考单图验收。

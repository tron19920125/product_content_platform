# 字体库许可与交互验收

## 交互模型

- 选中文本框后，右侧首先展示字体、字号、加粗、斜体、下划线和删除线等高频属性。
- 点击字体名称后，字体库在同一右侧检查器中替换属性面板，不新增页面底部区域。
- 字体库支持搜索、分类和最近使用；按 `Esc` 或点击“文本属性”返回。
- 字体卡片使用字体文件本身实时预览；大文件只在卡片进入可视区或当前文本使用时加载。
- 选中的字体和字形效果即时反映到画布；应用排版后由服务端确定性重绘透明文字层。

## 许可门槛

入库字体必须同时满足：

1. 可追溯到字体作者或 Google Fonts 的官方仓库；
2. 仓库包含 SIL Open Font License 1.1；
3. 许可证允许个人及企业商用、软件嵌入和随软件再分发；
4. 字体文件不被单独出售，部署包保留 OFL 全文；
5. API 暴露许可地址、覆盖范围、再分发说明和 `license_verified` 审计字段。

现有 ZCOOL 三款字体因公开授权历史存在争议，不再随产品分发。旧文字文档中的对应字体 ID 会回退到系统字体，不影响项目加载。

## 内容规划预览

- 商品框默认展示仓库内的演示商品参考图。
- 项目只要上传一张用途为“商品外观”的图片，内容规划立即优先展示最近上传的商品图。
- 标题和正文由浏览器测量容器后做二分缩放，保持原模板区域比例并完整显示；不再通过省略号或固定两行裁切。

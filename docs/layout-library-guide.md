# 版式库、页面模板、配方与生成指令

## 产品术语

### 版式库

版式库是同一交付画布规格下的一组页面骨架。一个库只对应一个固定尺寸，例如 `3840×2160`；页面预览按这个宽高比缩放展示，不要求在浏览器里按实际像素大小渲染。这样项目内模板能够稳定拼接，用户也能在创建项目时提前理解最终横竖比例。

版式库负责：

- 画布宽度、高度、方向和库名称；
- 对同尺寸模板进行分类；
- 限制项目只能选择本库模板，避免规划与生产尺寸漂移。

内置库为 `2048×2048`、`3840×2160` 和 `2160×3840`。自定义库尺寸需通过 GPT Image 2 的尺寸校验；最大正方形预设为 `2880×2880`。

### 页面模板

页面模板是可版本化的版式骨架，不承载某次项目的营销文案。模板定义：

- 标题框和正文框；
- 内容安全区；
- 商品允许区与商品核心区；
- 适用页面类型；
- 场景提示和构图说明。

所有框都使用相对画布的百分比坐标保存，因此无论编辑器预览放大或缩小，生产时都能还原为准确像素。草稿可以修改或删除；发布版本是审计快照，不允许原地覆盖。需要调整已发布模板时，系统强制创建下一版本，旧项目仍锁定原版本。

### 配方

配方是可复用的生产策略，不是页面坐标本身。它绑定：

- 一个已发布 Prompt 版本；
- 可使用的已发布页面模板集合；
- 默认生成质量和候选数量；
- 参考图策略与质检策略。

同一个版式库可以有多套不同视觉风格的配方；同一套模板也可以被多个兼容配方复用。项目生产时可以覆盖配方的默认质量，但不会修改已发布配方。

### 单页生成指令

实际发送给图片模型的 Prompt 在任务开始时动态装配，来源包括：

1. 配方中已发布的基础场景 Prompt；
2. 当前页面的类型和视觉目标；
3. 页面模板的场景提示与构图说明；
4. 模板的商品允许区、商品核心区和标题/正文留白区；
5. 商品事实以及当前绑定的商品、细节、品牌和场景参考素材；
6. 明确的无营销文字、无虚构型号、无水印要求。

标题和正文的字面内容不会发送给生图模型。模型负责根据参考素材生成商品本体、新角度、材质、光影和环境；生成完成后，系统再按模板的标题框和正文框创建确定性透明文字层并合成。这能同时保留参考图驱动的生成能力和准确可编辑的中文排版。

## 完整生产链路

```text
选择版式库（固定尺寸）
  → 为每页选择已发布模板版本
  → 选择配方和本次质量
  → 动态装配单页 Prompt 与全部参考图
  → 模型生成包含商品和场景、但不含营销文案的 base.png
  → 按标题框/正文框生成 text_layer.png
  → 合成为 final.png
  → OCR、规则与多模态质检
  → 人工确认、重排文字或重生成底图
  → 单图、分层 ZIP 或长图导出
```

每个候选会记录版式库 ID、模板 ID 与版本、实际画布尺寸、配方、Prompt 版本、模型参数、参考素材数量和图层来源，便于重现和审计。

## 项目内的约束

- 新建项目先选版式库，系统按库生成内容规划。
- 切换版式库时，页面会映射到新库中兼容页面类型的模板，并要求重新确认规划。
- 页面只能保存当前库内且支持该页面类型的模板。
- 实际生产继续校验库、模板版本和尺寸，不能只依赖前端选择器。
- 候选卡和项目预览使用真实宽高比；坐标框按比例缩放，不按实际像素铺满屏幕。

## 质检框的含义

候选图上显示的框是质检证据叠层，不会写入最终图片：

- 标题框、正文框：核对后期文字是否位于模板规定区域；
- 安全区：检查主要内容是否贴边或被裁切；
- 商品允许区：商品主体可以出现的最大范围；
- 商品核心区：期望商品视觉重心覆盖的区域；
- 问题框：OCR、遮挡、溢出或多模态审查发现问题时的定位证据。

关闭质检标注后即可查看干净成图，下载与导出的 `final.png` 不包含这些框。

## 内置演示

仓库跟踪 `examples/showcases/` 中的三套演示资产。首次启动会创建三个已完成示例项目：正方形、最大横版和最大竖版。它们的画面构图、文字区域和场景设计不同，同时展示相同商品参考在不同画布中的适配结果。示例是部署种子数据，重复启动不会重复创建，也不要求用户先跑一次耗时的生图任务。

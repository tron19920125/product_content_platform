# AI 商品图文内容生产与智能质检平台 IP 方案

## 1. 产品定位

本平台是一套面向商品营销内容生产的自研 AI 平台，将商品资料管理、文案策划、图片生成、模特应用、模板排版、智能质检、结果修复和批量交付整合为一条完整生产链路。

平台解决的不是单次“生成一张图片”，而是：

> 通过结构化商品资料和经过验证的生成配方，稳定、批量地生产符合品牌要求的多页商品图文，并利用智能质检持续提升生成质量。

本方案暂不包含 3D 模型、白模、材质贴图及工业设计渲染链路。

## 2. 产品目标

1. 降低商品图文内容的制作门槛和生产成本。
2. 将文案、图片、模板和品牌规范沉淀为可复用的生产资产。
3. 保证同一商品多页内容以及同一系列商品之间的视觉一致性。
4. 通过自动质检减少文字错误、商品变形、主体遮挡和版式问题。
5. 建立 Prompt、模型、模板、生成结果和质检数据之间的持续优化闭环。

## 3. 目标用户

- **内容运营人员**：录入商品资料，选择生成方案，审核并导出内容。
- **电商运营人员**：批量生产商品主图、详情页和营销素材。
- **设计人员**：建设模板、字体、品牌规范和视觉风格资产。
- **AI 运营及管理员**：维护 Prompt、模型、生成配方、质检规则和版本。

## 4. 产品核心流程

```text
创建商品项目
    ↓
录入商品资料、参考图和品牌要求
    ↓
AI 生成文案与多页内容规划
    ↓
系统推荐模板和生成配方
    ↓
生成商品图、场景图或模特图
    ↓
文字与图片分层合成
    ↓
智能质检、自动调整和候选结果排序
    ↓
人工审核与局部修改
    ↓
批量导出，并将优质结果沉淀为可复用资产
```

Prompt 管理、生成配方和质检反馈贯穿整个流程，在后台形成持续优化闭环。

## 6. 核心模块说明

### 6.1 商品项目与资料中心

平台将所有输入统一整理为结构化的 `ProductProfile`，包括：

- 产品名称、品类和系列；
- 关键卖点、规格、参数和限制信息；
- 品牌定位、目标用户和投放渠道；
- 商品参考图、品牌参考图和模特选择；
- 页面数量、图片比例、语言及输出格式；
- 禁用词、合规要求及不可修改的产品事实。

后续文案、Prompt、图片生成和质检全部使用同一份商品档案，避免不同环节信息不一致。

### 6.2 AI 文案与页面策划

系统根据商品档案生成一套多页内容规划 `PagePlan`，并将文案划分为统一层级：

- 一级标题：页面核心主题；
- 二级标题：主要卖点；
- 三级标题：功能说明；
- 四级标题：参数或补充信息；
- 五级标题：备注、免责声明等辅助内容。

页面类型可以包括：

- 商品主视觉页；
- 核心卖点页；
- 多卖点分栏页；
- 功能说明页；
- 使用场景页；
- 参数信息页；
- 商品对比页；
- 模特展示页；
- 活动促销页；
- 品牌故事页。

### 6.3 模板与图文分层合成

平台首期建设一组覆盖主要页面类型的标准模板，并支持后续自定义扩展。

图片生成阶段只负责商品、场景、光影和构图；文字由排版引擎独立合成。该方式能够：

- 避免 AI 生成乱码或错误文字；
- 使用企业自有或已授权字体；
- 保证多页内容的字号和版式一致；
- 精确控制主体安全区和文字区域；
- 支持用户修改文案后快速重新排版，无需重新生成底图。

### 6.4 AI 图片生成与模特应用

根据不同业务场景选择生成模式：

- 商品参考图生成营销场景；
- 商品主体替换到指定背景；
- 使用参考图控制构图、颜色和氛围；
- 选择预设模特生成商品展示图；
- 对局部问题进行重绘；
- 一次生成多张候选图供质检和筛选。

对于高品质内容，平台可以采用多候选生成和人工审核；对于标准化内容，则优先使用固定模板和已发布配方进行批量生产。

### 6.5 智能质检与自动修复

智能质检覆盖以下方面：

1. **商品一致性**：主体结构、颜色、Logo、关键部件和外观是否偏离参考图。
2. **文字准确性**：产品名称、数字、单位、参数和卖点是否正确。
3. **图文关系**：文字是否遮挡商品主体，构图是否保留足够安全区。
4. **版式规范**：字号、对齐、边距、对比度和页面一致性是否合格。
5. **品牌规范**：颜色、字体、视觉风格和禁用内容是否符合品牌要求。
6. **综合质量**：清晰度、美观度、营销表达和页面完整性是否达到发布标准。

可确定性修复的问题，例如文字位置、字号、颜色、边距和对齐，由排版引擎自动处理；商品变形或场景错误等生成问题，则重新调用图片模型生成。

## 7. Prompt 资产与生成配方

### 7.1 Prompt 资产与实验中心【借鉴 PO】

Prompt Optimizer 提供了 Prompt 优化、变量管理、版本历史、多模型测试和结果比较等能力。本平台借鉴这些方法，建设面向商品内容生产的专家工作台，而不是照搬一个通用 Prompt 编辑器。

计划吸收的能力包括：

- Prompt 变量定义和变量预览；
- 原始版、实验版和发布版管理；
- Prompt 版本差异比较与回滚；
- 固定商品输入下的多版本真实出图对比；
- 固定 Prompt 下的多模型效果、成本和时延比较；
- 根据质检问题形成 Prompt 修改建议；
- 通过审核后将 Prompt 发布为正式生产资产。

普通业务用户不需要看到复杂 Prompt，只填写商品资料并选择使用场景。Prompt 编辑和实验能力仅向设计、AI 运营和管理员开放。

参考来源：[Prompt Optimizer 官方仓库](https://github.com/linshenkx/prompt-optimizer)。

### 7.2 企业内部配方库【借鉴 PG】

Prompt Garden 使用分类、标签、变量、示例图片和导入标识组织 Prompt。本平台借鉴这种资产展示方式，建设企业内部“生成配方库”。

每张配方卡包括：

- 配方名称和适用场景；
- 适用品类、品牌档位和渠道；
- 所需输入变量；
- Prompt 发布版本；
- 图片模型和默认参数；
- 版式模板及质检规则；
- 示例输入和生成结果；
- 质检分数和使用效果；
- 来源、授权和发布状态；
- 一键套用入口。

可参考 Prompt Garden 的[情绪文案壁纸卡](https://garden.always200.com/prompts/emotional-copy-journal-wallpaper-card/)和[知识摘要卡](https://garden.always200.com/prompts/mobile-knowledge-summary-card/)在变量、示例参数和结果预览方面的组织方式，但内部配方及示例内容由平台自行建设。

### 7.3 生成配方定义

生成配方 `PublishedRecipe` 是平台最核心的生产资产，由以下内容组成：

```text
业务场景
+ Prompt 及版本
+ 商品和品牌变量
+ 图片生成模型及参数
+ 版式模板
+ 负向约束
+ 参考图
+ 质检规则
+ 黄金输入输出案例
+ 发布及授权状态
```

业务人员使用的是经过验证的“高端冰箱主视觉配方”“空调年轻化场景配方”等生产方案，而不是一段孤立的 Prompt。

## 8. 生成、质检与持续优化闭环

1. 从内部配方库选择当前正式配方。
2. 将商品档案自动填入配方变量。
3. 生成一组正式结果和候选实验结果。
4. 对生成结果执行商品、文字、版式和品牌质检。
5. 比较不同 Prompt 版本或模型的质量、成本和时延。
6. 由专家确认候选版本是否优于当前版本。
7. 合格版本发布为新的正式配方，不合格版本保留为实验记录。
8. 新配方进入内部配方库，供后续商品批量复用。

平台的核心优势不是单纯“可以优化 Prompt”，而是所有生产 Prompt 都有真实生成结果、质检证据、版本记录和明确的发布状态。

## 9. 产品界面规划

### 9.1 业务工作台

- 创建和管理商品项目；
- 上传资料和参考图；
- 选择输出页面、模板和模特；
- 接受系统推荐的生成配方；
- 生成多页商品内容；
- 查看质检问题和修改建议；
- 批量导出。

### 9.2 设计与 AI 专家工作台

- Prompt 编辑、变量预览和版本管理；
- Prompt 与模型出图实验；
- 模板和品牌规范管理；
- 生成配方审核、发布和回滚；
- 质检规则和阈值管理；
- 模特、字体和参考素材授权管理；
- 效果、成本和使用数据分析。

## 10. 4—8 周建设范围

| 阶段 | 建设内容 | 主要交付结果 |
|---|---|---|
| 第一阶段 | 商品资料、文案策划、页面规划和基础图片生成 | 能从商品资料生成一套基础图文内容 |
| 第二阶段 | 模板中心、图文分层合成和批量生成 | 能按统一模板批量生产多页商品图 |
| 第三阶段 | 接入智能质检、问题定位和基础自动修复 | 能检查并处理文字、遮挡、版式和商品一致性问题 |
| 第四阶段 | Prompt 版本、真实出图 A/B 测试和生成配方 | 能验证、发布和回滚稳定的生产配方 |
| 第五阶段 | 内部配方库、黄金案例、试运行和验收 | 形成可被持续复用的完整生产平台 |

4 周版本可先覆盖一个重点品类、3—5 种模板、基础图片生成、图文合成和基础质检。

6—8 周版本可扩展至 10—20 种模板、内部配方库、Prompt 实验、多模型比较和完整质检闭环。

## 11. 首期不纳入范围

- 3D 模型、白模和工业设计渲染；
- 公开 Prompt 社区、点赞、投稿和交易市场；
- 面向普通用户的完整通用 Prompt 编辑器；
- Chrome 插件和独立桌面客户端；
- 复杂 MCP 及 Function Calling；
- 一次性覆盖所有商品品类；
- 完全无人审核的生产配方自动发布。

## 12. 知识产权与实施边界

Prompt Optimizer 使用 [GNU AGPL v3.0 only](https://github.com/linshenkx/prompt-optimizer/blob/develop/LICENSE) 许可证。平台可以借鉴其产品流程、实验方法和数据设计，但不建议直接复制其代码进入计划闭源交付的自研 IP；如需复用代码，应先完成许可证和法务评估。

Prompt Garden 中的 Prompt、示例图片和媒体内容也不能默认用于商业生产。内部配方库应自行建设，并记录每项 Prompt、模板、字体、图片、模特和参考素材的来源、授权状态及使用范围。

企业模型密钥应由后端模型网关和密钥管理系统统一保管，不在浏览器前端直接保存或暴露。

## 13. IP 核心价值

平台最终沉淀的不是零散图片，也不是零散 Prompt，而是：

> 一套由商品资料、文案结构、Prompt、模型、模板、品牌规范、生成结果和质检标准共同组成的、经过验证并可批量复用的商品内容生产体系。

由此形成以下自研 IP 资产：

- 结构化商品内容数据模型；
- 多级文案和页面规划能力；
- 商品图文模板及分层合成能力；
- 商品一致性和图文质量审查能力；
- Prompt 资产、版本和实验体系；
- 经过质检验证的企业生成配方库；
- 从生产数据和质检反馈中持续优化的闭环能力。
